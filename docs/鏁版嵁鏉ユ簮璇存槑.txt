芯链 · 芯片采购实验室 / 教学数据说明

所有供应商、客户、员工、制造商、EDU-* 料号、报价、订单和物流为虚构教学内容。
不存在真实品牌的原厂授权、产品销售、技术指标保证或市场报价背书。

1. docs/chip_catalog.json 是物料、供应商、MOQ、封装、参数、价格和库存的唯一教学目录。
2. scripts/generate_chip_assets.py 生成运行时 seed、完整导入 SQL、报价 HTML 和智能体 URL 映射。
3. Java 启动使用 src/main/resources/db/schema.sql 与 seed.sql；重复启动不改写已有业务数据。
4. 24 个采购物料对应 12 个 MPN，每个 MPN 两家供应商。相同 MPN / 封装 / 温度等级可以用于报价对比。
5. 价格均为人民币/片的课堂参考单价，不含真实税费与运费分解。历史订单价格按生成规则模拟。
6. 历史订单日期相对首次导入当天；以后重启不会重新滚动日期。需要新一轮样本请启用空库。
7. 报价页是 chip-lab-v2 固定教学快照。
8. 门户芯片图形为项目内 SVG 与 CSS；没有加载外部商品图片、品牌标识、商城模板或在线字体。
9. 智能体会话使用独立 chip_agent_db。
